# External Standards and Prior Art References

Standards and primary references this package was designed around:

- Development Container Specification
- Compose Specification
- Open Container Initiative (OCI) image/runtime/distribution specifications
- Podman rootless / daemonless local runtime model
- Kubernetes Pod Security Standards (Restricted)
- Kubernetes ephemeral containers limitations
- Nocalhost-style direct cluster attach and sync ergonomics
- Kompose as a convenience converter, not as the platform contract

See the package manifest for current validation date and artifact checksums.
